Make smaller dataset uploads

Download this HTML file and open the saved copy directly in your browser. Saving dataset parts may be blocked inside a chat preview. Open the saved HTML file in Chrome, Edge, or Firefox.

Choose one of your original Roboflow ZIP files. This creates small numbered ZIP parts and a manifest. Your original file stays unchanged.

Everything happens in this browser. This page has no server, external scripts, or network access. Each part is about 24 MiB, below the chat transfer limit.

  1. Select one original dataset ZIP and click Prepare parts.
  2. Click each Download link below, including the manifest. In supported browsers, Save all files to a folder saves everything together.
  3. Attach all numbered ZIP parts and the .parts.json manifest to the chat. Repeat for your second original dataset ZIP.
